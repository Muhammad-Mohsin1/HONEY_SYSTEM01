# Honey Sales Management System

A client-side Honey Sales & Billing Management System built with HTML, CSS and Vanilla JavaScript.

## Features
- Admin login
- Honey 250g / 470g products
- Price and stock management
- Sales and multiple line items
- Paid / Partial / Remaining payment status
- Inventory deduction and restoration
- Customer summaries
- Dashboard revenue metrics
- Printable invoices / browser Save as PDF
- Sales history
- Reports
- LocalStorage persistence
- JSON backup and restore
- Demo-ready structure

## Default login
Username: `admin`
Password: `admin123`

## Run
Open `index.html` in a browser. For best browser compatibility, use a local static server (for example VS Code Live Server). No backend is required.

## Important
LocalStorage is browser/device specific and is not a secure production database. Use the Backup & Restore feature regularly.
